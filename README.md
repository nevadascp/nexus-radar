# NEXUS Radar

Личный радар Dota 2: Lua → Firebase Realtime Database → GitHub Pages.

**Сайт:** https://nevadascp.github.io/nexus-radar/

**Демонстрация:** https://nevadascp.github.io/nexus-radar/?demo=1

## Установка

1. Отключить прежний радар. Поместить `nexus_radar.lua` в папку Lua-скриптов Umbrella.
2. Поместить личный `nexus_radar.json` из приватного комплекта в `configs/` Umbrella. В репозитории этого файла нет.
3. Перезагрузить скрипты, открыть NEXUS Radar, включить и нажать Start. Ссылка появляется в поле меню.
4. Друг открывает ссылку без регистрации. Stop удаляет сессию; New link сначала удаляет прежнюю и только затем создаёт новую. Дождаться успешного статуса закрытия. При сбое сети повторить Stop после восстановления.

Ключ отправителя нужен только владельцу. Его нельзя отправлять другу или коммитить в GitHub. При утрате ключа владелец Firebase может запретить UID в правилах базы, затем создать новую пару.

## Возможности

- Карта из установленной Dota с калибровкой ±9472 мировых единиц; масштаб, панорамирование, поворот и слои.
- Герои, последнее наблюдение в тумане, HP/MP, предметы, способности, статистика и байбек, когда API предоставляет эти данные.
- Варды, руны, здания, крипы, курьеры, лагеря, Рошан, Tormentor и хроника событий.
- Автоматический мобильный интерфейс, ручной выбор вида, экономная отрисовка и настройка сглаживания.
- TURBO: свежий пакет после освобождения соединения. Один HTTP-запрос в полёте, ограниченная очередь событий, кеши и бюджет сбора. Абсолютная мгновенность зависит от сети и сервера.

## Протокол и доступ

`config.json` содержит публичную конфигурацию Firebase, а не секрет отправителя. Просмотр использует Web SDK только для realtime-подписок, без регистрации и без записи. Список сессий закрыт. Сессия доступна по 128-битному случайному идентификатору в URL fragment `#s=…`; он не отправляется GitHub как часть HTTP URL. Для внешних изображений отключён referrer. Просмотр не даёт права записи.

Запись разрешена только конкретному UID в `database.rules.json`, с проверкой владельца, версии и монотонного номера пакета. Stop удаляет запись; запоздавший PATCH не может создать её заново без владельца. Сайт очищает отображение при отзыве доступа. Уже полученные данные и скриншоты отозвать невозможно. Пользователь Firebase Console с правами владельца сохраняет административный доступ.

Неизвестные значения отображаются как неизвестные; прогноз движения ограничен 80 мс и не используется для героев в тумане. Данные старше 6 с помечаются как устаревшие. Демонстрация всегда явно отмечена и не подключается к базе.

## Локальная проверка

```sh
node --test tests/*.test.mjs
python -m http.server 8765 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8765/?demo=1`. Сайт buildless, GitHub Pages публикует корень main; `.nojekyll` обязателен. Правила Firebase публикуются отдельно владельцем проекта. Не публикуйте шаблон с `PAIRED_WRITER_UID` вместо рабочего файла.

Используются только собственный проект `nexus-radar-eb31b` и собственный репозиторий. Ограничения бесплатного Firebase Spark сохраняются; частота TURBO и число зрителей влияют на объём передачи. Платные услуги автоматически не включаются.

Иконки интерфейса нарисованы для NEXUS. Dota 2 и игровые изображения принадлежат Valve; источники и калибровка — в ASSETS.md. Сборщик Lua переработан на основе предоставленного пользователем скрипта; сохранены авторские комментарии qLocalization. Работа с реальной игрой требует доступного API Umbrella и должна проверяться в клиенте.
