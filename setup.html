Игра на ПК.
Радар — где удобно.

Отправитель NEXUS собирает доступные ему данные матча, Firebase передаёт обновления, а сайт рисует карту в браузере друга. ПК отправляет данные наружу; открывать порты или держать браузер на игровом ПК не нужно.

01 / ОТПРАВИТЕЛЬ

Установи скрипт

  1. Скачай nexus_radar.lua и помести его в папку скриптов Umbrella. Отключи прежний радар, чтобы не было двойной нагрузки.
  2. Личный файл nexus_radar.json из выданного тебе комплекта помести в папку configs Umbrella. Он содержит доступ отправителя — другу отправляется только ссылка.
  3. Перезагрузи Lua-скрипты. В меню NEXUS Radar включи отправитель и нажми Start.
  4. Скопируй ссылку из поля меню и отправь другу. На сайте регистрация не нужна.
Stop удаляет сессию в Firebase и закрывает дальнейшее получение данных по ссылке. Уже увиденные сведения или скриншоты отозвать невозможно. New link закрывает старую сессию и создаёт другую.

02 / ПРОСМОТР

Открой сессию

Вставь ссылку, которую создал твой отправитель. Адрес сессии хранится после # и не передаётся GitHub при загрузке страницы.

Режимы передачи

ECO экономит ресурсы. FAST подходит для обычной игры. TURBO отправляет свежий пакет сразу, как освобождается соединение. Частота зависит от сети, FPS и доступности Firebase; очереди старых пакетов нет.

Сайт автоматически подстраивается под телефон и ПК. В верхней панели можно выбрать режим вручную. Настройки позволяют выбрать плавное движение, низкую задержку и экономную отрисовку.

Что означает точка на карте. Зелёная/красная рамка — видимый герой. Жёлтая — последняя позиция, сообщённая API отправителя. Серая — последнее наблюдение. Сайт показывает давность; данные в тумане могут быть неполными. Таймеры объектов опираются на наблюдения скрипта.

Хостинг: GitHub Pages — файлы сайта, Firebase Realtime Database — поток данных. Ни сайт, ни отправитель не используют базу прежнего автора. При сбое сети Stop может потребовать повторного нажатия после восстановления соединения; результат удаления показывается в меню.
